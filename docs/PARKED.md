# fileCon — Parked ideas

Status: living list · Related: [Build Plan](BUILD-PLAN.md) · [Conversions](CONVERSIONS.md) · [PRD](PRD.md) · [Index](INDEX.md)

Ideas we chose **not** to build yet, each with the moment to look at it again. Conversions that aren't scheduled live in [CONVERSIONS section 6](CONVERSIONS.md#6-ideas-not-scheduled); this list holds everything else (behavior, UX, tooling).

## 1. How this list works

- Every item has a **Revisit at** trigger: a BUILD-PLAN task, or an event such as "when FFmpeg tasks are written".
- A task with a trigger here carries a **Parked to review first** line in [BUILD-PLAN](BUILD-PLAN.md). Before starting that task, raise those items with the user and decide: adopt (write it into the matching doc and the task), re-park (new trigger) or drop (keep the row, status `dropped`, with the reason).
- New parked ideas are added here in the same change that parks them, never only in chat or memory.
- Status: `parked` · `adopted` (with where it went) · `dropped` (with why).

| P18 | **Verify container contents.** Zip-based (docx, xlsx, pptx, odt, ods, odp) and CFB-based (doc, xls, ppt) files are told apart by extension only, so a renamed zip passes detection and fails later in LibreOffice. Option: peek inside (zip entries `word/`, `xl/`, `ppt/`, `mimetype`; CFB directory stream names) and set `mismatch` | M0-5 review | [M1-4](BUILD-PLAN.md#m1-4-converters-and-combiner-), or sooner if misdetected Office files are reported | parked |
| P19 | **Find LibreOffice on any Windows drive.** Discovery only checks PATH and `C:\Program Files\LibreOffice`, but the installer lets users pick another drive and doesn't add itself to PATH, so a `D:` install shows as not found until the user sets the path by hand. Fixes: use `%ProgramFiles%` and `%ProgramFiles(x86)%` instead of a literal `C:`, and read the install folder from the registry (`reg query HKLM\SOFTWARE\LibreOffice\UNO\InstallPath`, run through `jobs/spawn`, tested with a fake `exec`). Needs a real Windows machine to verify | M1-3 review | [M1-8](BUILD-PLAN.md#m1-8-ci-matrix-) (a Windows runner exists), or sooner if users report LibreOffice not found | parked |

Also the CMYK jpg colours in viewers are unchecked | M1-4b review | [M1-7](BUILD-PLAN.md#m1-7-renderer-), when the options bar is built, or sooner if users report it | parked |
